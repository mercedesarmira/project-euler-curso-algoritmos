# Proyecto: 29 Problemas de Project Euler

**Curso:** Análisis de Algoritmos  

Este proyecto consiste en resolver **29 problemas de Project Euler** con enfoque en **diseño y análisis de algoritmos**.  

**Categoría de problemas**
- Categoría 1: 20 problemas, código y diseño propios, ejecución < 1 min.
- Categoría 2: 2 problemas, cómputo intensivo, ejecución ≤ 12 h.  
- Categoría 3: 2 problemas, asistencia de LLM solo para transpilar, ejecución < 1 min.  
- Categoría 4: 5 problemas, se permite ideación y fragmentos de LLM, ejecución < 1 min.  

Se incluye el análisis formal o empírico de 6 problemas.

**Estructura del proyecto:**

- `problemas/`: Carpeta que contiene los scripts independientes de cada problema.
- `colab_notebook.ipynb`: Notebook con análisis empírico de tiempos de ejecución y gráficos de complejidad.
